Encoder: Sentence-Transformers to convert movie metadata into high-dimensional vectors.

Vector Store: ChromaDB for efficient similarity searching and persistence.

Dataset: TMDB 1M Dataset (Kaggle), providing a massive corpus for diverse recommendations.

Tech Stack:

Core: Python 3.10+

ML/NLP: Sentence-Transformers, Scikit-learn

Database: ChromaDB (Vector database)
